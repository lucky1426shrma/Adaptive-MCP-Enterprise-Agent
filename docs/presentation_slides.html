Self-RAG & Corrective Retrieval (CRAG)
Hybrid Search Fused with Autonomous Context Sufficiency Evaluation
Agent Innovation
🔍 2-Stage Retrieval & Assessment
  • Stage 1: Hybrid Retrieval & Reranking
    BM25 + Qdrant Dense fused and re-ranked using ms-marco-MiniLM-L-6-v2.
  • Stage 2: Self-Reflection Gate (retrieval_assessment.py)
    Scores context relevance & sufficiency before allowing final answer generation.
🔄 Autonomous Loop Guard (CRAG)
  • Path A (High Sufficiency): Proceed directly to cited final answer.
  • Path B (Low Sufficiency): rag_loop_guard.py automatically rewrites search queries and triggers a second-pass fallback pass.
  • Force-Stop Safety: Gracefully degrades context if evidence cannot be found within iteration budgets.
